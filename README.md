# Analysis code for the NML umbrella manuscript

This repository contains the behavioural, fibre-photometry, and image-analysis
workflows used for the umbrella manuscript.

## Fibre photometry

- [`fibre-photometry/README.md`](fibre-photometry/README.md) provides the
  figure-to-sensor index and links to each analysis entry point.
- [`fibre-photometry/dlight`](fibre-photometry/dlight/README.md) contains the
  dLight workflows (Figs. 2 and 3, and Supplemental Fig. 7).
- [`fibre-photometry/caddis`](fibre-photometry/caddis/README.md) contains the
  cADDis workflows (Fig. 3 and Supplemental Fig. 7)
- [`fibre-photometry/exrai-akar2`](fibre-photometry/exrai-akar2/README.md)
  contains the ExRai-AKAR2 workflows (Fig. 3 and Supplemental Fig. 7)
- [`fibre-photometry/gcamp`](fibre-photometry/gcamp/README.md) contains the
  GCaMP6m workflows (Supplemental Figs. 3, 4, and 5)

Each workflow readme describes its expected input layout, configuration, and
run order.
