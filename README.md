# Goulton et al (2026)
## Formerly NML umbrella manuscript.

This repository contains the behavioural, fibre-photometry, and image-analysis
code used for Goulton et al (2026).

See readme files within each analysis folder for details of analysis type, environment requirements and workflows from source data to final outputs.

Raw data will be made available upon manuscript publication via Figshare: https://doi.org/10.6084/m9.figshare.34465431.
